# Show me.

Rich Markdown for reflections and engrams.

The presentation benchmark measures whether agents present reflections well. On its test split (claude-haiku-4-5, three items, one run per arm) the share of checks passed was 0.80 without a skill, 0.82 with the intelligence skill and 0.85 with the presentation skill added. No arm passed an item outright yet. The agent never called the skills tool in these runs.
